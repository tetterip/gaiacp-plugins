# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it is installed from the plugin catalogue.

## [1.0.1] - 2026-11-17

- Moved out of GaiaCP into the plugin catalogue: install it under Settings → System → Plugin catalogue. An install that
  had it keeps it, with its settings and data, and updates it from the catalogue from now on. No change to how it
  works.

## [1.0.0] - 2026-10-27

- Ollama as an AI service of Settings → AI assistant: an open model (Llama, Qwen, Gemma…) on your own server or computer through Ollama's OpenAI-compatible API, so texts never leave your machines; its address, a model of your choice and an API key only for a proxy that asks for one; Test connection lists the models it has
- Off in a new install
